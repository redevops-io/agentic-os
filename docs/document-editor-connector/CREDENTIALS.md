# Credentials introduced by the connector (names only, never values)

All are supplied at runtime from Vault-provided environment; nothing is committed, generated by tooling or defaulted.

| Name | Class | Used for | If absent |
|---|---|---|---|
| `DOCEDITOR_ONLYOFFICE_URL` | OWNER-SUPPLIED SHARED (not secret) | origin of the externally managed Document Server | every call returns `not_configured` |
| `DOCEDITOR_ONLYOFFICE_JWT_SECRET` | THIRD-PARTY-ISSUED (the editor's own `JWT_SECRET`) | HS256 signing/verification of editor requests and session configs | every call returns `not_configured`; never generated |
| `DOCEDITOR_POLICY_SIGNING_KEY` | OWNER-SUPPLIED SHARED | verifies tenant `signed_policy` blocks that loosen the classification matrix | signed policies are rejected (stricter-only) |
| `DOCEDITOR_CONTENT_SIGNING_SECRET` | SELF-GENERATED (optional) | signing key for the editor-facing content URLs; random per process when unset | fine for one replica; set it for more than one |

Existing platform secrets reused unchanged: `AGENTIC_OS_APPROVAL_SECRET`, `AGENTIC_OS_CONTROL_TOKEN`,
`AGENTIC_OS_TENANT_TOKENS`.
