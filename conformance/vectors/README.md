# Shared conformance vectors

Generated by `conformance/gen_vectors.py` from the Python reference (`python conformance/gen_vectors.py`; CI/tests run
`--check` and fail if a committed file is stale). Every language port must assert these files **byte for byte**:

| File | Behaviour | Python reference |
|---|---|---|
| `chain.json` | per-mission hash chain: canonical text and hash; tamper/delete/reorder/legacy reports | `agentic_os/mission/store.py` |
| `inputs_digest.json` | `inputs_sha256` bound by approvals (ensure_ascii=True canonicalisation) | `agentic_os/mission/approval.py` |
| `action_summary.json` | what the approver is shown (allowlist, e-mail masking, truncation) | `approval.action_summary_of` |
| `approval_ttl.json` | approval expiry rule | `approval.approval_expired` |
| `assurance.json` | assurance sensors over event lists | `agentic_os/mission/assurance.py` |

Ports must decode numbers with a number-preserving mode (Go `UseNumber`, Kotlin `BigDecimal`/raw tokens): the chain
hashes the *text* of numbers (`1.0` vs `1`, `1e+16`), and the chain canonicaliser differs from the approval one
(`ensure_ascii=False` and code-point key order vs `ensure_ascii=True`).
