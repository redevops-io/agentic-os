Apps

Checked apps run alongside the control plane via Docker. Unchecking stops that app's own container; shared systems another checked app still needs (for example Metabase) are left running.

AI agents

Connect an AI agent (for example Gemini CLI, Claude Desktop or a local model) to this installation. Each agent gets its own credential, can only read projects, missions and sources, and stops working after 30 days. It cannot approve anything. Disconnect it here at any time. The credential stays in a private file on this device and is never shown.
