# Launcher icons: TEMPORARY neutral artwork

These six files are TEMPORARY neutral artwork, generated by `scripts/make_neutral_icons.py`
(Python standard library only; no letters, no text, no fonts, no third-party content, no model output;
a rounded square with a slate gradient, one pale rounded diamond and one round cut-out).

They replace the previous icons, which carried a letter mark. The owner decided (2026-11-05) not to retain that
mark while decision D-LIC-11 ("Launcher icons and the mark") is unresolved; D-LIC-11 stays OPEN. This artwork is a
stand-in, not a brand decision, and nothing here is a statement about rights or clearance either way.

Formats: PNG 8-bit RGBA (32, 128, 256 for the `@2x` file, 512); `icon.ico` holds 16, 24, 32, 48, 64, 128 and 256
(every image a PNG); `icon.icns` holds the standard iconset sizes 16 to 1024 (including the `@2x` variants) as PNG.
The files carry no metadata (no timestamps, no text chunks, no software name).

Regenerate with `python scripts/make_neutral_icons.py`; `tests/test_launcher_icons.py` checks that the files equal
the generator output, that the previous artwork is nowhere in the repository, and that this table is current.
The compiled window icon (embedded into the launcher binary at build time from `32x32.png`) is checked by the Rust
test `the_compiled_default_window_icon_is_the_temporary_neutral_32x32`.
